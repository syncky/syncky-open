    How the demo works

    This page is the whole agent. When you start it, it makes a key pair in the browser and registers a demo hub with the Syncky relay. The iPhone joins that hub with the code and proves it by picking the code you see here.

    The iPhone seals each Health message for this tab's key and your browser decrypts it; the relay cannot read them. The relay's own notices about the hub (who joined or left, the hub's state) are plain. The relay deletes a sealed message once this tab has fetched and acknowledged it; data from a phone that has not yet picked the code is held unread until it does.

    What Relay keeps: the demo hub with its sealed messages, the names and public keys of this tab and your iPhone, and the pairing, for about 1 hour from the start (a few seconds more while the iPhone is still joined); then it deletes the hub and the iPhone shows that the agent left. End demo removes this tab's agent at once; if the iPhone is still joined, the hub itself lasts until that hour ends. Like every Relay hub it leaves request logs for up to 7 days, keyed statistics hashes for 90 days and Cloudflare's 30-day recovery copy, as the privacy policy describes. A reload starts over with new keys.

    The page loads no analytics and makes no request except to the Syncky relay.
